# 設定你的網路來使用 Phylode

裝置要向你的 Mac 查詢網站，Phylode 才能保護它。這份說明教你只改路由器上的一項設定，就讓網路上的
每台裝置都這樣做。如果無法變更路由器的設定，也可以[逐台設定裝置](#逐台設定裝置)。

每個品牌的路由器選單都不一樣，所以下面寫的是要找的設定名稱，而不是確切的選單路徑。這份說明還沒有
在每一種路由器上驗證過；如果某個步驟跟你的路由器對不上，請[回報問題](https://github.com/Strofai/Phylode/issues/new/choose)。

## 開始之前

- 安裝 Phylode 並執行 `sudo phylode on`。它最後印出的內容會包含你的 Mac 在網路上的位址，例如
  `192.168.1.20`，下面會用到。
- 讓這台 Mac 在服務網路期間保持開機、不進入睡眠。你可以在「系統設定」中，設定顯示器關閉時不讓
  Mac 自動進入睡眠。
- 先想好停電怎麼辦。在 Mac 桌上型電腦上，選擇蘋果選單 >「系統設定」，按一下
  「能源」，然後開啟「於電力故障排除後自動重新開機」
  （[Apple 支援](https://support.apple.com/zh-tw/guide/mac-help/mchlp1168/mac)）。
  如果開啟了 FileVault，Mac 重新開機後會停在登入視窗，磁碟解鎖之前 Phylode 無法啟動，網路上的
  裝置在這段期間都查不到網站。停電後請登入一次，或開啟「遠端登入」，從另一台裝置透過 SSH 解鎖磁碟
  （macOS Tahoe 26 以後，[Apple 支援](https://support.apple.com/en-us/124963)）。關閉 FileVault
  就不必等待，但磁碟上的所有資料（包括查詢記錄）都不會加密。
- 準備好路由器的管理頁面或 App。管理位址通常印在路由器上，多半是 `192.168.1.1` 或
  `192.168.0.1` 這類位址。

## 步驟 1：替你的 Mac 保留固定位址

你的 Mac 位址一變，裝置就找不到 Phylode。在路由器的設定中，把 Mac 目前的位址保留給它。路由器上
這項設定可能叫做 **DHCP 保留**、**位址保留**、**靜態租約**或**固定 IP**。

## 步驟 2：讓路由器發送你的 Mac 的位址

在路由器的 **DHCP** 或 **LAN** 設定中，找到 **DNS 伺服器**欄位。把你的 Mac 的位址填在第一個
DNS 伺服器，其他欄位留空。

不要「以防萬一」再填一個公用 DNS 伺服器（例如網路業者的，或 1.1.1.1）當第二個伺服器。裝置不會把
第二個伺服器當成備援：兩個都會隨意使用，而透過第二個伺服器查詢的網站都不會被過濾。萬一你的 Mac
無法連線，多填一個也幫不上 Phylode；讓網路保持暢通的關鍵，是讓 Mac 一直開著。

裝置下次加入網路時就會套用新設定。想立刻套用，可以在裝置上把 Wi-Fi 關閉再開啟。

## 步驟 3：檢查 IPv6

如果你的網路使用 IPv6，路由器可能會在步驟 2 的設定之外，另外告訴裝置它自己的 IPv6 DNS 伺服器。
Apple 裝置會使用收到的每一個 DNS 伺服器，因此這些裝置有時會略過 Phylode。請找 **IPv6 DNS**、
**RDNSS** 或 **DHCPv6** 相關設定，並擇一處理：

- **指向你的 Mac。** 如果你的 Mac 有 `fd` 開頭的 IPv6 位址（在「系統設定」>「網路」> 你的網路服務
  >「詳細資訊」> TCP/IP 中可以看到），就填這個位址。使用這類位址的裝置，Phylode 預設就會回應。
- **使用你的 Mac 的公用 IPv6 位址**（`2` 或 `3` 開頭）之前，先在 `/usr/local/etc/phylode.conf`
  加上你的網路的 IPv6 前綴，例如 `serve_network = 2001:db8:1:2::/64`，再執行一次
  `sudo phylode install`。少了這一行，Phylode 不會回應透過公用位址連過來的裝置，這些裝置就什麼都
  查不到。
- **關閉路由器的 IPv6 DNS 伺服器**，如果路由器允許的話。

## 步驟 4：確認已經生效

在同一個網路上的另一台 Mac 打開「終端機」，執行：

```bash
dig iadsdk.apple.com +short
```

顯示 `0.0.0.0`，表示這次查詢經過 Phylode 並被封鎖。顯示其他位址，表示那台 Mac 還在使用別的
DNS 伺服器：把它的 Wi-Fi 關閉再開啟，並檢查步驟 2 和步驟 3。

過一天之後，在執行 Phylode 的 Mac 上執行 `phylode report`，就能看到整個網路的查詢與封鎖次數。

## 逐台設定裝置

如果無法變更路由器的設定，就在每台要保護的裝置上設定 DNS 伺服器，並移除那裡列出的其他 DNS 伺服器。

- **Mac：** 選擇「蘋果」選單 >「系統設定」，按一下「網路」，按一下網路服務，按一下「詳細資訊」，
  然後按一下 DNS。（[Apple 支援](https://support.apple.com/zh-tw/guide/mac-help/mh14127/mac)）
- **iPhone 或 iPad：** 前往「設定」> Wi-Fi，點一下網路旁的資訊按鈕，再點一下「設定 DNS」並選擇
  「手動」。（[Apple 支援](https://support.apple.com/zh-tw/guide/iphone/iphw5gjwl8k2/ios)）
- **其他裝置：** 在裝置的網路或 Wi-Fi 設定中找 DNS 設定。

沒有 DNS 設定的裝置，例如 HomePod 和許多智慧家電，只能透過路由器保護。

在 iPhone 和 iPad 上，這項設定只套用在單一 Wi-Fi 網路。在 Mac 上，它跟著網路服務走，所以 MacBook
到了其他 Wi-Fi 網路仍會向 Phylode 查詢，但那裡連不到它——帶著 Mac 外出前，請先改回自動取得。

## 不同的網路環境

- **家裡：** 在網路業者提供的路由器上完成步驟 1 到 4；如果你在業者的設備後面另外接了自己的路由器，
  就在自己的路由器上設定。業者的路由器不能改 DNS 伺服器時，可以在後面接一台自己的路由器，或逐台
  設定裝置。
- **辦公室或工作室：** 由管理網路的人在路由器或 DHCP 伺服器上改一次即可；執行 Phylode 的 Mac 最好
  使用有線網路。Phylode 只回應這台 Mac 自己接著的網段；路由器另外接的網段（例如分開的訪客網路或
  VLAN）上的裝置，要為那個網段加一行 `serve_network`。
- **學校：** 和辦公室相同。除非加上 `serve_network`，Phylode 只回應私有位址，因此使用公用位址的
  網路要先加上這幾行。

## 遇到問題時

- **部分裝置什麼都打不開：** 它們可能透過 Phylode 沒有設定回應的公用 IPv6 位址連到你的 Mac（見
  步驟 3），或你的 Mac 進入了睡眠或關機。
- **停電後什麼都打不開：** 如果開啟了 FileVault，Mac 正停在登入視窗。請登入，或透過 SSH 解鎖
  （見[開始之前](#開始之前)）。
- **某台裝置還是看得到廣告：** 它可能使用自己的加密 DNS（有些瀏覽器和 App 會這麼做）、iCloud
  私密轉送，或手動設定的 DNS。這些 Phylode 都無法過濾。
- **要全部復原**，就把步驟 2 和步驟 3 改過的 DNS 伺服器欄位清空。裝置下次加入網路時，就會改回使用
  路由器的 DNS。

其他問題請執行 `phylode diagnostics`，並把輸出附在[問題回報](https://github.com/Strofai/Phylode/issues/new/choose)中。
